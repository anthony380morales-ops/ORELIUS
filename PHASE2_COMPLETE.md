## 🎨 Color Coding

### System Status
- **Green** = Operational / Normal
- **Yellow** = Warning
- **Red** = Error / Critical

### Resource Usage
- **Green** = < 50% (Healthy)
- **Yellow** = 50-80% (Moderate)
- **Red** = > 80% (High)

### Audit Log Severity
- **Blue** = Info
- **Yellow** = Warning
- **Red** = Error/Critical
